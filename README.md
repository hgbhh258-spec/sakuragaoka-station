一个由 Opus 5.5 生成的日本樱花小镇，完全由 Three.js 构建，无需复杂配置，打开浏览器输入网址即可运行。

A Japanese cherry-blossom town generated by Opus 5.5, built entirely with Three.js — no complex setup required, just open a browser and enter the URL to run it.

## 关于此项目 · About

一个可行走的第一人称视角、动漫赛璐璐渲染风格的日本郊区樱花车站场景，纯粹基于 [three.js](https://threejs.org/) 构建——无需构建步骤，无需外部 3D 资源。场景中的一切（建筑、列车、树木、标识、纹理、音效）均由代码程序化生成。

A walkable, first-person anime cel-shaded Japanese suburban sakura station built with plain [three.js](https://threejs.org/) — no build step, no external 3D assets. Everything (buildings, trains, trees, signage, textures, sound) is generated procedurally in code.

[MIT](LICENSE). 场景中的所有品牌、车站及地名均为虚构。
All brands, stations and place names in the scene are fictional.
